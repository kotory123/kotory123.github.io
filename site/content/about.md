## 고영민

전북대학교 컴퓨터공학과 3학년에 재학 중인 고영민입니다. 웹 화면(프론트엔드)을 만들고, 복잡한 데이터를 한눈에 보이게 정리하는 일을 좋아합니다.

## 관심 분야 {#interests}

**웹 프론트엔드**와 **전력 IT(에너지 데이터 시각화)**에 관심이 있습니다.

캡스톤디자인에서 배전계통 데이터를 다루는 웹 플랫폼의 화면을 맡으면서, 전문가가 아니어도 계통의 문제 위치를 바로 알아볼 수 있게 만드는 일이 실제 업무에 도움이 된다는 것을 느꼈습니다. 계산 결과를 숫자 표 대신 단선도의 색과 표로 바꿔 보여 줄 때 팀원과 자문 위원의 이해가 빨라지는 것을 보고 이 분야를 더 공부하고 싶어졌습니다.

## 학습 목표와 실행 계획 {#goals}

**목표:** 공기업 IT 직무에서 일할 수 있도록, 실제 데이터를 다루는 웹 서비스를 끝까지 만들어 배포해 보는 경험을 쌓는 것입니다.

**다음 행동:**

1. 캡스톤 플랫폼의 남은 화면(유스케이스)을 완성하고 팀 저장소에 PR로 반영합니다.
2. 이 포트폴리오 사이트에 활동 기록을 계속 추가하고, GitHub Actions 자동 배포를 유지합니다.
3. 정보처리기사와 컴퓨터활용능력 1급 취득을 준비합니다.
4. 4학년 1학기 인턴 지원을 목표로, 지원 전에 이 사이트와 캡스톤 결과물을 정리합니다.
