## 고영민

안녕하세요. 전북대학교 컴퓨터공학과 3학년 고영민입니다.
저는 웹 화면을 만드는 프론트엔드 개발에 관심이 많고, 지금은 캡스톤디자인 팀에서 프론트엔드를 맡고 있습니다.

## 관심 분야 {#interests}

제가 관심 있는 분야는 웹 프론트엔드와 전력 IT입니다.

원래는 화면 만드는 것 자체가 재미있어서 프론트엔드를 공부했는데, 이번 캡스톤에서 배전계통 데이터를 다루는 플랫폼을 만들면서 전력 쪽에도 관심이 생겼습니다.
처음에는 전압, 부하율 같은 숫자만 보면 뭐가 문제인지 저도 잘 몰랐는데, 이걸 단선도 위에 색으로 칠해서 보여 주니까 팀원들도 문제 위치를 바로 찾을 수 있었습니다.
이때 데이터를 사람이 이해하기 쉽게 보여 주는 일이 생각보다 중요하다는 걸 알게 됐고, 이 분야를 더 공부해 보고 싶어졌습니다.

## 학습 목표와 실행 계획 {#goals}

제 목표는 공기업 IT 직무로 취업하는 것입니다.
그래서 실제 데이터를 다루는 웹 서비스를 처음부터 배포까지 직접 해 보는 경험을 쌓으려고 합니다.

앞으로 할 일은 이렇습니다.

1. 캡스톤 플랫폼에서 남은 화면을 마무리하고 팀 저장소에 PR로 올리기
2. 정보처리기사, 컴퓨터활용능력 1급 준비하기
3. 이 포트폴리오에 활동을 계속 추가하기
4. 4학년 1학기에 인턴 지원하기 (지원 전에 이 사이트랑 캡스톤 결과물 정리)
