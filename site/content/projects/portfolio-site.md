**목적:** 내 소개와 활동을 한곳에 모으고, main에 push하면 자동으로 빌드·배포되는 흐름을 직접 만들어 보는 것입니다.

## 수행 과정 {#process}

1. **테마 선택:** 문서·블로그형이면서 메뉴·모바일 화면이 기본으로 갖춰진 PaperMod를 골랐습니다. 소개 글과 활동 글을 나눠 쓰기 쉽고, 별도 Node 빌드 없이 Hugo만으로 빌드됩니다.
2. **배포 준비:** 테마 ZIP을 풀고 수업 제공 스크립트로 GitHub Actions 워크플로를 만든 뒤, Settings → Pages에서 Source를 GitHub Actions로 정했습니다.
3. **내용 작성:** 설정(`site/pages.json`)과 글(`site/content/`)을 작은 단위로 나눠 커밋했습니다.
4. **점검과 수정:** 1440px·768px·390px 화면, 키보드(Tab) 이동, 링크와 404 요청을 확인하고 고쳤습니다.

## 만나 본 문제와 해결 {#troubleshooting}

- **배포 스크립트 중단:** 처음에 `git init`을 먼저 하고 스크립트를 실행했더니 "기존 Git 저장소에 배포 워크플로가 있습니다"로 멈췄습니다. 테마 ZIP 안의 기존 배포 파일을 스크립트가 안전하게 바꾸려면 Git이 없는 새 폴더여야 했습니다. 순서를 안내대로 바꿔(스크립트 실행 → `git init`) 해결했습니다.
- **없는 파일 요청:** 테마가 파비콘 파일을 요청하는데 파일이 없어 404가 났습니다. `site/static/`에 아이콘을 넣어 해결했습니다.
- **굵은 글씨 깨짐:** `**화면(React)**을`처럼 괄호 뒤에 조사가 바로 붙으면 마크다운 굵게 표시가 적용되지 않아 문장을 고쳤습니다.

## 배운 점 {#lessons}

설정을 바꿀 때마다 커밋하고 Actions 결과와 실제 화면을 확인하니, 어떤 변경이 어떤 결과를 냈는지 이력으로 남아 문제를 찾기 쉬웠습니다.
