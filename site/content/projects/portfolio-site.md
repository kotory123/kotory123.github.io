제 소개와 활동을 한곳에 모아 두고, main에 push하면 자동으로 사이트가 배포되는 과정을 직접 해 보려고 만들었습니다.

## 수행 과정 {#process}

1. 테마는 PaperMod를 골랐습니다. 메뉴랑 모바일 화면이 기본으로 잘 되어 있고, 소개 글과 활동 글을 나눠서 쓰기 편해 보였습니다.
2. 테마 ZIP을 풀고 수업에서 받은 스크립트로 GitHub Actions 배포 파일을 만든 다음, Settings → Pages에서 Source를 GitHub Actions로 바꿨습니다.
3. 설정 파일(`site/pages.json`)이랑 글(`site/content/`)을 조금씩 고치면서 그때그때 커밋했습니다.
4. 마지막으로 PC·태블릿·휴대폰 크기 화면, Tab 키 이동, 링크, 없는 파일 요청(404)을 확인하고 고쳤습니다.

## 만나 본 문제와 해결 {#troubleshooting}

처음에 `git init`을 먼저 하고 스크립트를 돌렸더니 "기존 Git 저장소에 배포 워크플로가 있습니다"라는 메시지가 나오면서 멈췄습니다.
알고 보니 테마 ZIP 안에 원래 배포 파일이 들어 있어서, 스크립트가 Git이 없는 새 폴더에서만 그 파일을 바꿔 주게 되어 있었습니다.
그래서 `.git`을 지우고 안내대로 스크립트를 먼저 실행한 다음 `git init`을 했더니 해결됐습니다.

그 밖에도 테마가 파비콘 파일을 찾는데 파일이 없어서 404가 나는 걸 발견해서 `site/static/`에 아이콘을 넣었고, 괄호 바로 뒤에 조사가 붙으면 마크다운 굵은 글씨가 깨지는 것도 문장을 바꿔서 고쳤습니다.

## 배운 점 {#lessons}

조금 고칠 때마다 커밋하고 Actions 결과랑 실제 화면을 같이 확인하니까, 뭐가 문제였는지 찾기가 훨씬 쉬웠습니다.
